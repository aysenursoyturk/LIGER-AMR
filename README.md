# LIGER-AMR
LIGER-AMR: A lineage-aware genomic feature selection and adaptive multi-view deep learning framework for antimicrobial resistance prediction in Staphylococcus aureus.


---


## Original genomic data

The original *Staphylococcus aureus* genomic datasets used in this
study were obtained from the Wheeler et al. repository:

https://github.com/nwheeler443/staph_gwas

Raw genomic data are not redistributed in this repository.
Users should obtain the original datasets directly from the source.
